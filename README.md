# Quake 4: Fishing Mod
### Denise Payumo - IT266

This mod repurposes and reimagines Quake 4 as a fishing simulator, semi-inspired by games like Stardew Valley and Webfishing!

---
## Objective 

Try to catch the most fish before the end of each day! Use the money earned to purchase upgrades for your fishing gear to increase your max score!

---
## Loading the Mod
1. Navigate to your Quake 4 folder
    *("Program Files (x86)\Steam\steamapps\common\Quake 4" for Steam version)*
2. Insert the "Fishing Mod" folder inside the Quake 4 directory
3. Launch Quake 4
4. From the main menu, click **MODS > fishing mod > Load**
5. Open the console with tilde '~' key
6. Enter **"map fishing"** to load into the mod map

## How to Play
| Action | Key | Description |
|--------|-----|-------------|
| **Cast Rod** | **Left Mouse Button (LMB)** | Cast your fishing line into the water |
| **Reel In (QTE)** | **Spacebar** | Press when prompted to reel in a fish |
| **Open Shop** | **B** | Open the shop menu for upgrades |

## Features

### Fishing rod (repurposed Grenade Launcher)
- Projectiles act as fishing bobber that hooks fish, prompting a QTE for to reel it in

### "Reel 'em in" QTE
- Upon hooking a fish, a mini game / quick-time event will appear
- Failing the QTE results in an unsuccessful catch

### Score System
- Successfully caught fish increases your **money** and **score**

### Time-based Gameplay
- In-game days last 60 seeconds
- Catch as many fish within the the time to set or beat your highscore

### Shop / Upgrade System
- Money can be used to purchase upgrades for fishing equipment.
- Upgrades can make it easier to reel in fish, find rarer fish, etc.
